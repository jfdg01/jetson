# Reglas de este experimento

Anulan el flujo de `/home/gara/jetson/CLAUDE.md` dentro de este directorio.

## Documentar solo bajo petición

**No escribas en `README.md` ni en `proof/README.md` salvo que el autor lo pida.** Tampoco en los
ledgers (`RESULTS`, `QUESTIONS`, `DECISIONS`, `SOURCES`). No hay "definición de done" documental
aquí: el barrido produce datos, la escritura llega cuando el autor la pide.

Motivo: el experimento genera hallazgos cada pocas horas y documentarlos según salen infla el
README con material que aún puede cambiar o morir con la siguiente tanda de resultados.

Mientras tanto:

- Los resultados en bruto (`raw/`) y el código sí se commitean sin preguntar.
- Los hallazgos van en el chat, no en ficheros.
- Cuando el autor pida documentar, se escribe todo lo pendiente de golpe.
